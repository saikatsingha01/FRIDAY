Deferred Improvements
DI-001 — AI Intent Detection

Current solution:

Keyword/rule-based intent detection.

Future solution:

Replace the internal implementation of detect_intent() with an LLM or dedicated intent classification model.

Reason for postponing:

Current architecture is already modular.
Time is better invested in speech, memory, security, and autonomy.

No changes to the rest of the codebase will be required when this upgrade happens.

Engineering Decisions

Decision:

Avoid implementing features that will later be completely replaced by AI.

Instead:

Build clean interfaces.
Build modular architecture.
Replace implementations later without changing the overall system.

This keeps Project Friday scalable while avoiding unnecessary work.
