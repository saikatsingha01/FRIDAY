# Known Issues

These issues are currently present in Project Friday. They are known, reproducible, and intentionally left unresolved because they do not block the current roadmap.

---

## Brain

### Basic Reasoning

The Brain currently performs simple routing rather than true reasoning.

Current limitations:

- Keyword-based decisions
- No semantic understanding
- No multi-step reasoning
- No planning

---

## Context System

Context retrieval relies on keyword matching.

Current limitations:

- Cannot understand meaning
- Weak follow-up conversation handling
- Cannot infer implied references
- Cannot combine multiple conversation turns

---

## Memory System

Automatic memory is functional but still heuristic-based.

Current limitations:

- Rule-based importance scoring
- Keyword-based categorization
- Keyword-based recall
- Duplicate detection is basic

---

## Intent Detection

Intent detection currently relies on manually defined rules.

Known issues:

- Similar sentences can produce different intents.
- Greetings with punctuation may occasionally fail detection.
- No semantic intent understanding.

---

## Response Quality

Current responses are functional but lack natural conversational flow.

Known issues:

- Robotic wording
- Limited variation
- Template-driven replies
- No personality adaptation

---

## Speech System

Speech pipeline is stable but has known limitations.

Known issues:

- Whisper occasionally mishears words.
- pyttsx3 voice sounds robotic.
- No interruption support.
- No wake-word activation.
- No speaker recognition.

---

## Debug Output

Development debug logs are still present.

These will be removed or replaced with proper logging after major architecture stabilization.
