API Keys / Secrets (documented only — actual values in environment):
- GEMINI_API_KEY — Google AI Studio API key for Gemini API with Google Search Grounding
  - Loaded via environment variable: GEMINI_API_KEY (or GEMINI_API_KEY_1, GEMINI_API_KEY_2, ...)
  - Multiple keys supported with automatic failover/cooldown
  - DO NOT commit actual keys to repository
- GEMINI_MODEL_1, GEMINI_MODEL_2, ... — Optional model override per API key
  - If not specified, the provider uses the default model (gemini-2.5-flash)
  - Example: GEMINI_MODEL_1=gemini-3.5-flash
  - DO NOT commit actual model configurations to repository
