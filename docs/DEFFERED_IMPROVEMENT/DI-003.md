DI-003 — Natural Language Understanding

Priority: High

Current limitation:

Friday understands only predefined sentence structures.

Future solution:

Use an LLM or local NLP model capable of understanding user intent rather than exact wording.

Expected improvements:

Handle paraphrased questions.
Understand requests naturally.
Distinguish statements, questions and commands.
Better conversational ability.

-----------------------------------------------------------------------------------------------------------------------------------------------

Engineering Decisions

Decision:

Avoid spending significant development time improving the temporary keyword-based intent system.

Reason:

The architecture already allows the intent detector to be replaced by an AI-based solution in the future without affecting the rest of the project.

Focus should remain on long-term features such as:

Speech Recognition
Vision
Memory
Security
Tool Usage
Autonomy
