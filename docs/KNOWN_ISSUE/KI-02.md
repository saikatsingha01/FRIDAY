## Issue: Speech Recognition Accuracy and Intent Correction

### Discovered:
During voice assistant testing, Whisper successfully converts speech to text, but unclear pronunciation or noisy speech can produce incorrect words.

Examples:
- User says: "shutdown"
- Whisper may output: "cut down" or another incorrect phrase

### Current Impact:
- Friday depends on the generated text from STT.
- Incorrect transcription can cause valid commands to fail.
- The current system works correctly when the transcription is accurate.

### Possible Solution:
Implement a speech understanding layer after STT.

Future pipeline:

Voice Input
↓
Whisper STT
↓
Text Correction / Intent Understanding
↓
Friday Command Handler
↓
Response

Possible improvements:
- Use context from Friday's memory to understand likely meanings.
- Add typo and pronunciation correction.
- Add LLM-based intent detection in the future.

### Decision:
Not implementing this immediately.

Reason:
The current STT pipeline is functional, and adding correction logic now may complicate debugging. This feature will be revisited after completing the basic voice assistant features, including TTS and better voice interaction.
