# KI-013 — Web search grounding guard incorrectly rejects valid temperature claims due to quotation-mark degree symbols

**Status:** Fixed (2026-08-15)
**Phases affected:** 5 (Tool Intelligence / Response Generation)
**Reported:** 2026-08-15
**Fixed:** 2026-08-15

## Symptom

User asked: "google the current weather in siliguri"

FRIDAY's web search pipeline worked correctly:
- Understanding detected `Need Web: True`
- `web_search` tool invoked successfully
- Gemini provider with Google Search grounding returned 5 grounded results
- Results contained specific weather measurements:
  - 85°F / 28°C current temperature
  - 97°F / 33°C RealFeel
  - 80% humidity, 66% humidity
  - 32°C (hot) with patchy rain
  - 27°C–34°C today's range
- `web_search` returned `status: success`
- ToolResult passed to brain correctly
- `build_prompt()` included results in TOOL RESULTS section
- LLM generated correct raw response with specific temperatures

**But FRIDAY's final spoken response was:**
> "I found some search results, but they don't contain verified current weather information. The snippets show general pages about the location but not the current temperature or conditions. You may need to check a weather service for the latest forecast."

This statement **contradicted the actual TOOL RESULTS** which contained verified current weather information.

## Root Cause

The web search grounding guard (`guard_web_response` in `src/core/response_generator.py`) was incorrectly triggering its fallback.

**Why:** Search result snippets use quotation marks (`"` / `\u201d`) as degree symbols (e.g., `28"C`, `82"F`), but the regex `_TEMP_RE` only matched the proper degree symbol `°` (e.g., `28°C`, `82°F`).

| Stage | Temperature extraction |
|-------|------------------------|
| Snippet claims | **NONE** (regex didn't match `"`) |
| Response claims | Temperature claims extracted correctly (LLM uses `°`) |

Result: Response had "ungrounded" temp claims → `_deterministic_web_fallback()` triggered with "no verified weather information" message.

## Fix Applied

**File:** `src/core/response_generator.py` (line 233)

```python
# BEFORE
_TEMP_RE = _re.compile(r"\b\d+(?:\.\d+)?\s*(?:°[cfk]|degrees?\s*(?:celsius|fahrenheit|kelvin)|[cfk])\b", _re.IGNORECASE)

# AFTER
_TEMP_RE = _re.compile(r"\b\d+(?:\.\d+)?\s*(?:[°\"\u201c\u201d][cfk]|degrees?\s*(?:celsius|fahrenheit|kelvin)|[cfk])\b", _re.IGNORECASE)
```

Added quotation marks (`"`, `\u201c`, `\u201d`) as valid degree indicators alongside the proper degree symbol `°`.
